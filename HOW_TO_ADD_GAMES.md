# Как пополнять «Тайную книгу»

Библиотека строит карточки автоматически из файла `games.json`.

## Добавить новую внешнюю игру

1. Откройте `games.json`.
2. Перед последней `]` добавьте запятую после предыдущей игры и вставьте новый объект:

```json
{
  "id": "my-new-game",
  "title": "Название игры",
  "description": "Короткое описание",
  "age": "8–12",
  "level": "A1",
  "skill": "Grammar",
  "topic": "Present Simple",
  "url": "https://.../",
  "icon": "🎮",
  "type": "external",
  "isNew": true
}
```

3. Сохраните файл и сделайте Commit в GitHub. Карточка появится автоматически.

## Если нужна собственная обложка

Положите картинку в папку `assets`, например `assets/new-game.webp`, и вместо `icon` добавьте:

```json
"image": "assets/new-game.webp"
```

## Что уже работает

- поиск по названию, описанию, теме и уровню;
- фильтр по возрасту;
- фильтр по уровню;
- фильтр по навыку;
- внешние игры открываются в новой вкладке;
- 3 исходные мини-игры внутри «Тайной книги» сохранены.

`fallbackGames` внутри `index.html` — резервный список на случай, если браузер не сможет загрузить `games.json`. Для GitHub Pages обычно используется `games.json`.
